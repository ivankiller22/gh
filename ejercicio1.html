Concepto y Tipos de Bases de Datos

Bases de datos Relacionales (RDBMS)

Las bases de datos relacionales organizan la información en tablas compuestas por filas (registros) y columnas (campos). Se basan en el modelo relacional y utulizan el lenguaje SQL para realizar consultas y gestionar los datos de manera estructurada.

Ejemplos de sistemas gestores relacionales populares con MySQL, PostgreSQL y Oracle.

Bases de datos No Relacionales (NoSQL)

Las bases de datos NoSQL están diseñadas para gestionar grandes volúmenes de datos no estructurados o semiestructurados. A diferencia de las relaciones, no requieren un esquema rígido y permiten escalabilidad horizontal.

Existen distintos tipos según el modelo de almacenamiento: orientadas a documentos, clave-valor, columnas o grafos. Un ejemplo representaativo es MonogoDB

Estructura de una Base de Datos Relacional

Componentes fundamentales

Para definir la estructura dentro de un modelo relacional se emplean los siguientes elementos:

  • Tablas (entidades): Objetos principales sobre los cuales se almacena informacion estructurada.
  • Campos (Atributos): Columnas individuales que definen las propiedades o características de cada entidad.
  • Registros (Túplas): Filas individuales que representan cada elemento o instancia concreta guardada en la tabla.
  • Claves primarias (Primary Keys): Campos cuyo valor es úmico e irrepetible para cada reigstro, garantzando su identificación

Recursos de interés

  • SGBD: El software que almacena, organiza y administra las bases de datos.
  • SQL: El lenguaje estándar que se usa para hablar con la base de datos y pedirle información.
  • Normalización: El proceso de organizar las tablas para evitar datos duplicados y errores.
